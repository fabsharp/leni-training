# Léni Training

Petites applications web d'entraînement scolaire, sans backend ni build — chaque
activité est un dossier autonome avec son propre `index.html`, publié via
GitHub Pages.

## Activités

- [`calcul-mental/`](calcul-mental/) — entraînement au calcul mental (tables de
  multiplication, addition/soustraction de 9, 19, 29, 39), avec suivi des
  erreurs, chronométrage par calcul, et défis chronométrés.
